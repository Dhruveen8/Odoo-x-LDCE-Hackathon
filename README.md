# 🌴 GlobeTrotter — Smart Multi-City Travel Planner & Luxury Resort Hub

> **Odoo x LDCE Hackathon 2026**
> Built with **React 18**, **Vite**, **Motion (`motion/react`)**, and an **Apple iOS 26 Liquid Glass UI**.

---

## ✨ Features

- 🫧 **Liquid Glass Interface**: Refractive 4-layer glassmorphism (specular highlight rim, deep blur, violet tint wash, depth shadowing).
- 🎬 **Cinematic Parallax Hero**: Parallax lagoon photography, scroll-driven fade transitions, and integrated booking widget.
- 🗺️ **13 Complete Views**:
  1. **Dashboard / Resort Hub**: Hero parallax, signature suites carousel, curated experiences, guest reviews, and 24/7 concierge.
  2. **My Trips**: Saved travel cards, progress tracking, and budget breakdown.
  3. **Itinerary Builder**: Multi-day activity planner with day-by-day sequencing.
  4. **Itinerary Timeline & Map**: Interactive canvas route visualizer with stopover waypoints.
  5. **City Search**: Global destination catalogue with average daily costs and quick-add filters.
  6. **Activity & Experience Library**: Curated excursions and cultural activities.
  7. **Budget & Financial Tracker**: Category breakdown charts, currency conversions, and budget alert indicators.
  8. **Trip Calendar**: Drag-and-drop schedule overview with milestone markers.
  9. **Public Shareable Link**: Live preview link for sharing trips with friends and family.
  10. **Profile & Preferences**: Home currency selector, dietary preferences, and travel styles.
  11. **Admin Analytics**: Platform-wide metrics, popular destinations, and booking stats.
  12. **Authentication View**: Switch accounts / login modal.
  13. **Create Trip Modal**: Fast multi-city trip creator with date pickers and guest counts.

---

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite
- **Animations**: `motion` (`motion/react` v13)
- **Icons**: Lucide React (`lucide-react`)
- **Effects**: `canvas-confetti`
- **Styling**: Vanilla CSS (Tailored Design Tokens & Liquid Glass System)

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Dhruveen8/Odoo-x-LDCE-Hackathon.git
cd Odoo-x-LDCE-Hackathon
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
